# 한자 연습장

https://2xqff.github.io/kanji/

제공된 PDF 두 개의 표를 옮긴 일본 상용한자 학습 사이트입니다.

- あ행 130자, か행 447자. 행은 PDF의 분류를 따릅니다(か행 자료는 が행 제외).
- 일본어 음독, 한국어 음훈, 형태별 일본어 훈독 563문제.
- 두 행을 함께 또는 각각 선택. 10/20/50/전체 문제, 객관식/직접 입력.
- 읽기가 없는 한자는 해당 유형에서 제외. 음독은 기재된 독음 전체가 정답입니다.
- 직접 입력은 히라가나/가타카나를 모두 인정하며 여러 음독은 쉼표·공백·가운뎃점으로 구분하고 순서는 상관없습니다.
- 정답·뜻 확인, 점수, 틀린 문제 재풀이. 입력 및 성적은 서버에 전송하지 않습니다.

## 데이터 출처

`일본_상용한자_아행_130자_A4_세로.pdf`, `일본_상용한자_카행_447자_A4_세로.pdf`에 기재된 한자, 구자체, 음독, 훈독, 학습용 뜻, 한국 훈음을 사용합니다. 원본의 빈칸은 임의로 채우지 않았습니다. PDF의 표기 또는 뜻에 오류가 있다면 `data.js`의 해당 항목을 수정하세요.

훈독 형태의 오쿠리가나 경계는 あ행 PDF의 하이픈 표기와 KANJIDIC 기반 [kanji-data](https://github.com/davidluzgouveia/kanji-data)의 `readings_kun`을 대조했습니다. 해당 사전으로 새 읽기나 뜻을 추가하지 않았습니다. 예: `ひろ.める` → `広める`.

## GitHub Pages

별도 빌드 없이 `main` 브랜치 루트에서 제공합니다. `index.html`, `style.css`, `app.js`, `data.js`를 함께 유지하세요. 외부 글꼴을 불러올 수 없는 환경에서도 시스템 글꼴로 작동합니다.

## 다른 행 추가

`data.js`에서 각 항목은 `id`, `group`, `subgroup`, `kanji`, `old`, `on`, `kun`, `korean`을 사용합니다. `kun`은 `reading`, `word`, `meaning`, `boundary`를 갖는 배열입니다. 자료를 검증한 뒤 행 선택 버튼을 추가하고 준비 중 표시를 갱신하세요.

## 검증

577자, 중복 없음, 행별 130/447자, 훈독 563개, 훈독 형태의 사전 경계 일치 확인. 브라우저에서 세 유형의 정상 채점, 직접 입력, 여러 음독의 순서·문자 정규화, 틀린 문제 재풀이, 중간 종료, 모바일 화면 넘침을 확인했습니다.
